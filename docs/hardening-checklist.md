# iPhone 하드닝 체크리스트 (iOS 26 기준)

> 표기: `설정 > …` = iPhone 설정 앱 경로 · ★ = 영향도 최상
> 적용 원칙: L1 → L2 → L3 순서. L3는 소송·분쟁·언론 노출 등 표적 가능성 높은 기간에 적용.

---

## L1 필수 (전원 적용 · 약 15분)

### A. 패치
- [ ] ★ **자동 업데이트 전체 ON** — `설정 > 일반 > 소프트웨어 업데이트 > 자동 업데이트` (iOS 업데이트 다운로드·설치, 보안 응답 및 시스템 파일 모두 ON)
- [ ] 현재 최신 버전 확인 — 보안 업데이트 공개 후 **72시간 내** 설치

### B. 잠금
- [ ] ★ **암호 6자리 이상 (권장: 사용자 지정 영숫자)** — `설정 > Face ID 및 암호 > 암호 변경 > 암호 옵션`
- [ ] **데이터 지우기 ON** (10회 실패 시 초기화) — `설정 > Face ID 및 암호` 최하단
- [ ] ★ **USB 액세서리 OFF** — `설정 > Face ID 및 암호 > 잠겨 있을 때 접근 허용 > 액세서리` OFF
- [ ] 잠금 상태 접근 차단: 제어 센터 · 메시지로 답장 · 지갑 · 홈 제어 OFF (같은 메뉴)

### C. Apple 계정
- [ ] ★ **이중 인증 ON** — `설정 > [이름] > 로그인 및 보안`
- [ ] **기기 목록 점검** — `설정 > [이름]` 하단 기기 목록에서 모르는 기기 제거
- [ ] 계정 비밀번호 고유값 사용 (타 서비스와 재사용 금지)

### D. 도난 기기 보호
- [ ] ★ **도난 기기 보호 ON + "항상"** — `설정 > Face ID 및 암호 > 도난 기기 보호` (보안 지연 "항상" 선택)

### E. 프로파일 / 앱
- [ ] ★ **미확인 프로파일 0개** — `설정 > 일반 > VPN 및 기기 관리` (본인이 설치하지 않은 항목 즉시 제거)
- [ ] App Store 외 경로 앱 설치 금지, 미사용 앱 삭제
- [ ] **앱 추적 요청 허용 OFF** — `설정 > 개인정보 보호 및 보안 > 추적`

### F. 메시지 / 웹
- [ ] **알 수 없는 발신자 필터링 ON** — `설정 > 앱 > 메시지 > 알 수 없는 발신자 필터링`
- [ ] **사기성 웹 사이트 경고 ON** — `설정 > 앱 > Safari`
- [ ] 문자·메신저 링크로 로그인·설치 요구 시 **무조건 무시** (공식 앱에서 직접 진입)

## L2 강화 (경영진 · 약 15분)

### G. 계정 최상위 보호
- [ ] ★ **보안 키(FIDO2) 등록 2개** — `설정 > [이름] > 로그인 및 보안 > 보안 키` (YubiKey 등 2개: 주·예비)
- [ ] **복구 키 생성** 또는 복구 연락처 지정 — `로그인 및 보안 > 계정 복구` (복구 키는 오프라인 금고 보관)
- [ ] ★ **iCloud 고급 데이터 보호 ON** — `설정 > [이름] > iCloud > 고급 데이터 보호`

### H. 통신(SIM) 탈취 차단
- [ ] ★ **SIM PIN 설정** — `설정 > 셀룰러 > SIM PIN` (기본 PIN은 통신사 확인, 변경 필수 / 3회 실패 시 PUK 필요)
- [ ] ★ **통신사 유심보호서비스 가입** (SKT·KT·LGU+ 고객센터/앱, 무료) — 타 기기 유심 사용 차단
- [ ] **명의도용방지서비스(M-Safer)** 가입 — msafer.or.kr, 신규 개통 시 알림·차단
- [ ] 금융앱 2차 인증을 SMS → 앱 기반/보안카드/OTP로 전환

### I. 네트워크 / 근거리
- [ ] **AirDrop "연락처만"** — `설정 > 일반 > AirDrop`
- [ ] **비공개 Wi-Fi 주소 "순환"** — `설정 > Wi-Fi > (네트워크 ⓘ) > 비공개 Wi-Fi 주소`
- [ ] **네트워크 연결 요청 OFF** — `설정 > Wi-Fi > 네트워크 연결 요청`
- [ ] iCloud 비공개 릴레이 ON (iCloud+) — `설정 > [이름] > iCloud > 비공개 릴레이`

### J. 권한 정리
- [ ] **앱 개인정보 보호 리포트 ON** 후 주 1회 확인 — `설정 > 개인정보 보호 및 보안 > 앱 개인정보 보호 리포트`
- [ ] 위치·마이크·카메라·로컬 네트워크·사진 권한 최소화 ("앱 사용 중"/"선택한 사진만")
- [ ] **안전 확인(Safety Check) 실행** — `설정 > 개인정보 보호 및 보안 > 안전 확인 > 공유 및 접근 관리`
- [ ] **암호 앱 > 보안 권장 사항** 확인 — 유출·재사용 비밀번호 전량 교체
- [ ] iMessage **연락처 키 확인 ON** — `설정 > [이름] > 연락처 키 확인` (핵심 상대와 확인 코드 대조)

## L3 최고 (표적 가능성 고위험 기간)

- [ ] ★ **차단 모드(Lockdown Mode) ON** — `설정 > 개인정보 보호 및 보안 > 차단 모드` (메시지 첨부 대부분 차단, 웹 JIT 비활성화, 미지 FaceTime 차단, 유선 연결 차단, 프로파일 설치 차단)
- [ ] **일일 재부팅** (비지속형 익스플로잇 제거) — 단축어 자동화로 루틴화
- [ ] 업무 전용 기기 분리 (개인 SNS·게임 앱 미설치)
- [ ] 민감 대화는 대면 또는 E2E 메신저 + 사라지는 메시지
- [ ] Apple **위협 알림** 메일/알림 수신 시 즉시 [사고 대응 런북](incident-response.md) 실행
- [ ] 월 1회 `scripts/mvt_scan.sh` 포렌식 점검

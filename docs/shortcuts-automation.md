# 단축어(Shortcuts) 보안 자동화 레시피

> 생성 경로: `단축어 앱 > 자동화 탭 > + > 개인용 자동화`
> 공통 설정: 각 자동화의 **"즉시 실행"** 선택, "실행 시 알림" ON(감사 추적용)
> 제약: iOS는 보안 설정(Lockdown·암호·프로파일 등) 자체를 단축어로 변경하는 액션을 제공하지 않는다 → **"실행"은 자동화, "판단"은 알림·체크로 유도**

| # | 이름 | 트리거 | 동작 | 차단 대상 | 주기 |
|---|---|---|---|---|---|
| A1 | 일일 재부팅 | 시간 03:30 + 충전기 연결 조건 | 기기 끄기 > **재시동** | 비지속형 제로클릭 익스플로잇 | 매일 |
| A2 | 공용 Wi-Fi 방어 | Wi-Fi 연결 (집·회사 외) | VPN 연결 + 블루투스 끔 알림 | 중간자 공격, 근거리 공격 | 이벤트 |
| A3 | 외출 근거리 차단 | 위치: 집 떠날 때 | AirDrop 수신 끔(제어 센터 안내) + Bluetooth 끔 | 근거리 무선 공격 | 이벤트 |

| A5 | 월간 포렌식 알림 | 매월 1일 09:00 | MVT 점검 리마인더 + 미리 알림 생성 | 잠복 감염 | 매월 |
| A6 | 비상 차단 | 수동 실행 (홈 화면/뒷면 탭) | 비행기 모드 ON + 위치 공유 중지 안내 + 런북 열기 | 실시간 침해 의심 | 수동 |

## A1 일일 재부팅

1. 자동화 > `특정 시간` > 03:30 · 매일 · **즉시 실행**
2. 액션 `배터리 상태 가져오기` → `만약 [충전 중]이면`
3. 내부 액션 `기기 끄기` → 옵션 **"재시동"**
4. `그 밖의 경우` → `알림 표시: "재부팅 보류: 충전 미연결"`

> 비고: 재부팅 후 첫 잠금 해제 전(BFU) 상태는 데이터 보호 수준이 가장 높다. 기기가 재시동 확인을 요구하면 아침 기상 알람 직후 1탭으로 실행하도록 시간 변경.

## A2 공용 Wi-Fi 방어

1. 자동화 > `Wi-Fi` > "모든 네트워크" 선택 · 즉시 실행
2. 액션 `현재 Wi-Fi 네트워크 가져오기`
3. `만약 [네트워크 이름]이 [집SSID, 회사SSID] 목록에 없으면`
   - `VPN 설정: [신뢰 VPN] 연결` (VPN 앱이 단축어 액션 지원 필요)
   - `알림 표시: "공용망 감지 — VPN 연결됨. 금융·로그인 금지"`

## A3 외출 근거리 차단

1. 자동화 > `떠날 때` > 집 주소
2. `Bluetooth 설정: 끔` (워치·이어폰 사용 시 생략)
3. `알림 표시: "외출 — AirDrop 수신 끔 확인"`

## A4 주간 보안 점검 (5분 루틴)

1. 자동화 > `특정 시간` > 매주 월요일 08:50
2. `메뉴에서 선택` 액션 (항목 = 아래 체크) → 미완료 항목은 `미리 알림 추가`
   - [ ] 소프트웨어 업데이트 최신
   - [ ] VPN 및 기기 관리: 프로파일 0
   - [ ] Apple 계정 기기 목록 이상 없음
   - [ ] 앱 개인정보 보호 리포트 이상 접근 없음
   - [ ] 암호 앱 보안 권장 사항 0건
3. `앱 열기: 설정`

## A5 월간 포렌식 알림

1. 자동화 > `특정 시간` > 매월 1일 09:00
2. `미리 알림 추가: "PC 연결 → scripts/mvt_scan.sh 실행 · 결과 보관"` (기한: 당일 18:00)

## A6 비상 차단 (패닉 버튼)

1. 단축어 탭(자동화 아님) > 새 단축어 "비상 차단"
2. 액션: `비행기 모드 설정: 켬` → `Wi-Fi 설정: 끔` → `Bluetooth 설정: 끔`
3. `URL 열기: [incident-response.md GitHub 링크]`
4. 배치: 홈 화면 + `설정 > 손쉬운 사용 > 터치 > 뒷면 탭 > 이중 탭`

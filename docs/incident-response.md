# 사고 대응 런북 — iPhone 해킹 의심 시

> 원칙: **증거 보존 → 격리 → 계정 회수 → 기기 복구 → 사후 검증**
> 금지: 의심 즉시 초기화 (포렌식 증거 소실 — 법적 대응 시 치명적)

---

## 0. 의심 징후 판정

| 징후 | 위험도 | 조치 |
|---|---|---|
| Apple 위협 알림(threat notification) 수신 | 🔴 최고 | 즉시 1단계 + 전문기관 의뢰 |
| 갑작스런 "SIM 없음"/서비스 불가 + 인증 SMS 미수신 | 🔴 최고 | SIM 스와핑 의심 → 즉시 통신사 정지 |
| 모르는 Apple 계정 로그인/기기 추가 알림 | 🔴 높음 | 2단계 즉시 |
| VPN 및 기기 관리에 미확인 프로파일 | 🟠 높음 | 스크린샷 후 제거, 3단계 |
| 이상 발열·배터리 급감·데이터 급증 (지속) | 🟡 중간 | MVT 점검 |
| 지인에게 내가 보내지 않은 메시지 | 🟠 높음 | 2단계 |

---

## 1단계 — 증거 보존 (0~30분)

- [ ] 화면 스크린샷: 알림, 프로파일, 기기 목록, 이상 메시지
- [ ] 발생 시각·현상 메모 (시간순 로그)
- [ ] PC에 **암호화 백업** 생성 (`scripts/mvt_scan.sh --backup-only`) — 원본 보존
- [ ] sysdiagnose 생성: 볼륨 업+다운+측면 버튼 동시 1~1.5초 → `설정 > 개인정보 보호 및 보안 > 분석 및 향상 > 분석 데이터`

## 2단계 — 격리 및 계정 회수 (30분~2시간) — **다른 신뢰 기기에서 수행**

- [ ] 의심 기기 비행기 모드 (전원 끄지 말 것: 메모리 증거)
- [ ] Apple 계정 비밀번호 변경 → 모든 기기 로그아웃 → 기기 목록에서 미확인 기기 제거
- [ ] 이메일·메신저·금융·클라우드 비밀번호 순차 변경 (이메일 최우선)
- [ ] 통신사: 유심 정지/재발급, 번호이동·개통 제한 확인
- [ ] 금융기관: 비대면 거래 일시 정지 요청

## 3단계 — 분석 (2~24시간)

- [ ] `scripts/mvt_scan.sh` 실행 → `detected` 항목 확인
- [ ] 탐지 시: 백업·결과 보존 후 전문기관 의뢰
  - KISA 인터넷침해대응센터 **118**
  - 경찰청 사이버수사국 (ecrm.police.go.kr)
  - Access Now Digital Security Helpline (시민사회·언론·인권 대상)
- [ ] 소송 관련 시 법률대리인에 증거 보존 사실 통지

## 4단계 — 복구

- [ ] 증거 확보 완료 후 **DFU 복원**(최신 iOS 재설치) → **백업에서 복원하지 말고 새 기기로 설정**
- [ ] 앱은 필요분만 App Store에서 재설치
- [ ] [하드닝 체크리스트](hardening-checklist.md) L1~L3 전량 재적용

## 5단계 — 사후 검증 (D+7, D+30)

- [ ] MVT 재점검 결과 clean
- [ ] Apple 계정 로그인 기록·기기 목록 이상 없음
- [ ] 재발 방지 항목 체크리스트 반영
